O que é o SICRO?

O SICRO (Sistema de Custos Referenciais de Obras) é o principal referencial de preços para obras de infraestrutura de transportes no Brasil. Gerenciado pelo DNIT, fornece custos unitários de referência para composições de serviços rodoviários em todos os 26 estados e o DF.

A tabela SICRO é atualizada trimestralmente e é o referencial obrigatório para orçamentos de obras rodoviárias financiadas com recursos federais. Os preços variam por estado conforme encargos sociais e custos regionais de insumos.

Composições SICRO são conjuntos de insumos, equipamentos e mão de obra com coeficientes técnicos que representam o custo unitário de execução de um serviço (ex: m³ de terraplenagem, m² de pavimento, m de bueiro).

O custo total de cada composição é dividido em:

  • A — Equipamentos: custo horário de máquinas e veículos
  • B — Mão de Obra: salários com encargos sociais por UF
  • C — Materiais: insumos consumidos no serviço
  • D — Atividades Auxiliares: transportes e subserviços

Perguntas Frequentes sobre o SICRO

Perguntas Frequentes

O Buscador SICRO é gratuito?
Sim, 100% gratuito, sem cadastro e sem limites de consulta. O objetivo é democratizar o acesso à tabela SICRO para engenheiros, gestores públicos, construtoras e órgãos de fiscalização.
Os dados são oficiais e atualizados?
Sim. Os dados vêm diretamente das planilhas oficiais publicadas pelo DNIT (Departamento Nacional de Infraestrutura de Transportes). A referência atual é Julho/2026, com 6.619 composições para todos os 26 estados e o DF.
O que é a tabela SICRO?
O SICRO (Sistema de Custos Referenciais de Obras) é o banco de dados oficial do DNIT com preços unitários de referência para obras rodoviárias e de infraestrutura de transportes. Contém composições de custos divididas em 44 grupos de serviço, atualizadas trimestralmente.
Como usar o SICRO em licitações?
O SICRO é o referencial obrigatório para orçamentos de obras rodoviárias financiadas com recursos federais. Use a busca para localizar composições pelo código ou descrição, consulte os custos para o seu estado e exporte as referências para o orçamento.
Qual a diferença entre SICRO e SINAPI?
O SICRO (DNIT) cobre obras de infraestrutura rodoviária: estradas, pontes, viadutos, terraplenagem, sinalização. O SINAPI (CEF + IBGE) cobre construção civil predial: casas, prédios, escolas, hospitais. São sistemas distintos para tipos de obras diferentes.
Qual a diferença entre SICRO e SICRO 2?
O SICRO 2 foi o sistema anterior (2003–2017) com ~4.800 composições e códigos de 5 dígitos. O SICRO atual (novo SICRO, desde 2017) tem 44 grupos (G03–G71), códigos de 7 dígitos, Cadernos Técnicos por grupo e metodologia revisada pelo DNIT.
